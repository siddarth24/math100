16.3 — Lagrange multipliers

Find the best value of f(x,y)f(x, y)f(x,y) when you are forced to stay on a fixed constraint path g(x,y)=kg(x, y) = kg(x,y)=k (like a fixed budget) using Lagrange multipliers: fx=λgxf_x = \lambda g_xfx​=λgx​, fy=λgyf_y = \lambda g_yfy​=λgy​, and g(x,y)=kg(x, y) = kg(x,y)=k.

The intuition: hiking on a 3D landscape $z = f(x, y)$

Picture z=f(x,y)z = f(x, y)z=f(x,y) as the elevation zzz of a mountain above a map with East-West coordinate xxx and North-South coordinate yyy. A partial derivative fxf_xfx​ simply asks: if I freeze yyy (walk purely East) and take a tiny step in xxx, how steep is the hill? Because yyy is frozen, you treat yyy like a plain number (such as 555) while differentiating with respect to xxx. Peaks and valleys happen where the ground is flat in both directions at once (fx=0f_x = 0fx​=0 and fy=0f_y = 0fy​=0).

  • "Find fxf_xfx​ (or ∂f/∂x\partial f / \partial x∂f/∂x)" → pretend every yyy in the formula is a constant number and differentiate normally with respect to xxx. (Do the reverse for fyf_yfy​.)
  • "Interpret fx(a,b)=cf_x(a, b) = cfx​(a,b)=c in context" → when x=ax = ax=a and yyy is held fixed at bbb, increasing xxx by 111 unit changes the output by roughly ccc units.
  • "Find and classify critical points" → solve fx=0f_x = 0fx​=0 and fy=0f_y = 0fy​=0 together, then plug each point into D=fxxfyy−(fxy)2D = f_{xx}f_{yy} - (f_{xy})^2D=fxx​fyy​−(fxy​)2: if D>0D > 0D>0 and fxx<0f_{xx} < 0fxx​<0 it is a peak (local max); if D>0D > 0D>0 and fxx>0f_{xx} > 0fxx​>0 it is a bowl (local min); if D<0D < 0D<0 it is a mountain pass (saddle point).
  • "Absolute max/min on a closed shape (like a rectangle or disk)" → check the flat spots inside the shape and walk along the outer boundary edges/corners, then compare all the heights f(x,y)f(x, y)f(x,y).
  • "Optimize f(x,y)f(x, y)f(x,y) subject to a constraint g(x,y)=kg(x, y) = kg(x,y)=k" → use Lagrange multipliers: solve fx=λgxf_x = \lambda g_xfx​=λgx​, fy=λgyf_y = \lambda g_yfy​=λgy​, and g(x,y)=kg(x, y) = kg(x,y)=k together (usually by eliminating λ\lambdaλ first).
